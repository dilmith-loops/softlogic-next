2. DETAILED REMEDIATION PATCHES APPLIED

PATCH-01 Enforced Bearer Token Authentication on All Administrative APIs
Verified

In api/index.php, a centralized authentication middleware function was created that validates incoming Authorization: Bearer [token] headers against active database tokens. All administrative endpoints (/admin/stats, /admin/views, /admin/exam-starts, /admin/users, /admin/profile, /admin/export) now invoke this guard.

function requireAdminAuth(PDO $db): array { $authHeader = $_SERVER['HTTP_AUTHORIZATION'] ?? $_SERVER['REDIRECT_HTTP_AUTHORIZATION'] ?? ''; if (!preg_match('/Bearer\s+(\S+)/i', $authHeader, $matches)) { http_response_code(401); echo json_encode(["success" => false, "message" => "Unauthorized: Authentication token is missing or malformed."]); exit; } $token = trim($matches[1]); $stmt = $db->prepare("SELECT u.id, u.name, u.email, u.role FROM admin_tokens t JOIN users u ON t.user_id = u.id WHERE t.token = ? AND t.expires_at > ? LIMIT 1"); $stmt->execute([$token, date('Y-m-d H:i:s')]); $user = $stmt->fetch(); if (!$user) { http_response_code(401); echo json_encode(["success" => false, "message" => "Unauthorized: Administrator session has expired or token is invalid."]); exit; } return $user; }
PATCH-02 Hardened .htaccess Web Server Rules & Injected Security Headers
Verified

The root .htaccess file was upgraded to block direct access to internal folders, database dumps, source files, and lockfiles, while injecting critical security headers:

# Pass Authorization header through CGI/LiteSpeed RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}] # Block access to hidden files and internal development directories RewriteRule "(^|/)\." - [F,L] RewriteRule ^(backend|frontend|storage|tests|vendor)/ - [F,L] RewriteRule \.(sql|sqlite|lock|xml|md|log|env|yml|yaml|ts|tsx|sh)$ - [F,L] RewriteRule ^(package|composer)\.(json|lock)$ - [F,L] # Injected Security Headers Header set X-Content-Type-Options "nosniff" Header set X-Frame-Options "SAMEORIGIN" Header set Referrer-Policy "strict-origin-when-cross-origin" Header set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" Header set Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=()" Header unset X-Powered-By
PATCH-03 Brute-Force Login Rate Limiting & Telemetry Flooding Protection
Verified

Added a dedicated login_attempts table tracking failed login attempts per client IP. If 5 consecutive failed attempts occur within 15 minutes, the endpoint returns HTTP 429 Too Many Requests. Additionally, POST /views and POST /exam-starts enforce rate limits preventing automated script flooding.
